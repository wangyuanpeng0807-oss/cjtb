# 淘宝商品主图/详情一键导出（油猴脚本）

在淘宝/天猫商品详情页一键导出**主图、详情图、商品描述**到你自选的本地目录。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展（建议 Chrome / Edge 111+）。
2. 打开 Tampermonkey 管理面板 → 实用工具 → 导入文件，选择 `taobao-item-export.user.js`；
   或新建脚本，把文件内容整体粘贴进去并保存。
3. 确认脚本已启用（默认在淘宝/天猫详情页自动生效）。

## 使用

1. 打开任意淘宝/天猫商品详情页（如 `item.taobao.com/item.htm?id=...` 或 `detail.tmall.com/...`）。
2. 页面右下角会出现「淘宝导出」悬浮面板（右上角「—」可折叠）。
3. 点击「选择目录」，在系统弹窗中选择保存位置。目录会被记住，通常不需要重复选择；
   浏览器重启后再抓取，若弹出一次授权确认，点「允许编辑」即可（这是浏览器的安全机制，不是脚本出错）。
4. 点击「① 抓取并保存当前宝贝」，等待日志显示"完成"即可。
   也可以通过 Tampermonkey 菜单中的「抓取当前宝贝」触发。

## 导出结果

在所选目录下生成（以宝贝「秋季爆款女装」为例）：

```
秋季爆款女装.txt            商品信息 + 参数 + 描述 + 图片地址清单（UTF-8 带 BOM，记事本不乱码）
秋季爆款女装主图/主图_01.jpg 主图，按顺序编号，保留真实扩展名
秋季爆款女装主图/主图_02.jpg
秋季爆款女装详情/详情_01.jpg 详情图，按顺序编号
秋季爆款女装详情/详情_02.jpg
```

## 说明与注意事项

- 需要浏览器支持 File System Access API（Chrome / Edge 111+）。
- 不支持时脚本自动降级：用 GM_download 下载到浏览器默认下载目录，并按相同规则建子目录。
- 目录授权过期时，点击抓取会再次弹出授权提示，确认即可。
- 图片下载并发 3，单张失败自动重试 2 次，失败只记日志不中断整体流程。
- 脚本会自动滚动页面、点击「图文详情」标签以触发懒加载，请勿在抓取期间手动操作页面。
- 仅供个人学习/备份自用，请遵守平台规则与图片版权。

## 常见问题

- **面板没出现？** 确认当前页面域名在脚本 @match 列表内，且脚本已启用。
- **详情图为空？** 部分商品详情为视频或结构改版，可重试一次；脚本日志会提示走了哪条提取链路。
- **改了保存目录？** 再点一次「选择目录」即可，新目录会被记住。
